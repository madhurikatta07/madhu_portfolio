# 🎨 Design System & UI Specifications

> **Project:** Madhuri Katta — AI/ML Portfolio  
> **Aesthetic Philosophy:** Futuristic AI/Tech Dark Mode — Sleek, modern, and professional (70% Deep Dark, 20% Electric Blue/Cyan, 10% Purple/Neon Accent).

---

## 🌈 Color Palette System

| Token | Hex Code | Purpose / Usage |
|---|---|---|
| `--bg-main` | `#050816` | Main App Background (Deep Space Navy) |
| `--bg-secondary` | `#080B1A` | Alternate Section Background |
| `--bg-card` | `#0F172A` | Card & Container Surface Background |
| `--color-primary` | `#2563EB` | Primary Brand Blue (Buttons, Active States) |
| `--color-cyan` | `#06B6D4` | Accent Cyan (Badges, Highlight Text) |
| `--color-sky` | `#38BDF8` | Focus Rings, Secondary Accents |
| `--color-purple` | `#7C3AED` | Gradient Midpoint, Accent Tags |
| `--color-magenta` | `#EC0AA8` | Neon Highlight & Badge Accents |
| `--color-pink` | `#FF2BD6` | Glow Effects & Subtle Highlights |
| `--text-main` | `#F8FAFC` | Primary Headings & Bold Text |
| `--text-muted` | `#94A3B8` | Body Text, Subtitles, Meta Info |
| `--border-color` | `#1E293B` | Card Borders, Section Dividers |
| `--color-hover` | `#60A5FA` | Hover State for Links and Buttons |

### Signature Gradients
* **Brand Gradient:** `linear-gradient(90deg, #2563EB, #7C3AED, #EC0AA8)`
* **Text Gradient:** `linear-gradient(135deg, #38BDF8 0%, #818CF8 50%, #C084FC 100%)`
* **Glow Shadow:** `0 0 30px rgba(37, 99, 235, 0.25)`

---

## 🔤 Typography & Font Hierarchy

### Font Families
* **Display / Headings:** `'Poppins', sans-serif` (Weights: 500, 600, 700)
* **Body / UI Elements:** `'Inter', sans-serif` (Weights: 300, 400, 500, 600)
* **Code / Badges / Metrics:** `'JetBrains Mono', monospace` (Weights: 400, 500)

### Type Scale
| Element | Font Size | Weight | Line Height |
|---|---|---|---|
| Hero Title | `3.5rem` (56px) | `700` (Bold) | `1.1` |
| Section Title | `2.25rem` (36px) | `700` (Bold) | `1.2` |
| Card Title | `1.25rem` (20px) | `600` (Semi-Bold) | `1.3` |
| Body Text | `1.0rem` (16px) | `400` (Regular) | `1.6` |
| Badges & Tags | `0.85rem` (13.6px) | `500` (Medium) | `1.4` |
